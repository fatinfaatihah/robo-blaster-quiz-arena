ROBO-BLASTER QUIZ ARENA
=======================
Cara deploy: upload isi folder ini (index.html) ke hosting statis
(Netlify, Vercel, GitHub Pages, Cloudflare Pages, dll). Tidak perlu build.
Bisa juga langsung dibuka dengan klik dua kali index.html.

Catatan:
- Butuh internet untuk memuat Three.js (cdnjs) dan PeerJS (jsDelivr).
- Multiplayer di luar claude.ai memakai PeerJS (server publik 0.peerjs.com),
  jadi pemain harus bisa mengakses server itu. Disarankan deploy dengan HTTPS.
- Soal agama/diniyyah sebaiknya dicek dulu oleh guru/ustaz.
